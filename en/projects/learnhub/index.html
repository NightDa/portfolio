LearnHub

A mini online learning platform (LMS) with courses, lessons and quizzes.

Overview

A mini online learning platform (LMS) built as a monorepo: teachers publish courses made of ordered lessons and quizzes, students enroll, track their progress lesson by lesson and take quizzes with multiple retakes. Admins manage users and courses.

What I built

  • JWT authentication with three roles (student, teacher, admin) and role guards on the API and the front end.
  • Public course catalog with search, category and level filters, sorting and pagination.
  • Enrollment and progress tracking, with a completion percentage per course.
  • Multiple-choice quizzes with retakes and stored attempt history.
  • Interactive API documentation with Swagger (OpenAPI).
  • Fully containerized with Docker Compose and continuous integration via GitHub Actions.
